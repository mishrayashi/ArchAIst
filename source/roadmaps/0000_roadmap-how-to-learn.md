Before any roadmap, internalise *how* to study, or you'll waste months. Most people fail not from lack of intelligence but from bad learning habits.

## The five rules of learning to code

1. **Build, don't just watch.** Tutorials feel productive but watching ≠ knowing. For every hour of learning, spend an hour *building* something yourself. This is the #1 rule.
2. **Type every example by hand.** Copy-pasting teaches your clipboard, not your brain. Retype code, break it on purpose, see the errors, fix them.
3. **Embrace errors.** Error messages are not failure — they are the computer *telling you exactly what's wrong*. Read them. Google the exact text. This single skill separates pros from quitters.
4. **Spaced repetition.** Revisit a topic after 1 day, 3 days, 1 week. The Interview Bank here is perfect for this — drill a few questions daily.
5. **Learn just-in-time, not just-in-case.** Don't try to learn *everything* about a tool before using it. Learn the 20% you need to build the thing, build it, and the rest sticks naturally.

## Set up your free toolkit (one evening)
- **VS Code** — your code editor (free, code.visualstudio.com).
- **Python** — install from python.org (or Anaconda for a batteries-included setup).
- **Git + a GitHub account** — to save your code and show your work to employers.
- **A notebook** — Jupyter (`pip install jupyterlab`) for experimenting. You already have `coding.ipynb` — use it!
- **DBeaver** or the VS Code SQL extension — to practise SQL against a real database.

## How long does it take?
Honest ranges, studying seriously:
- **Career switcher, ~15 hrs/week:** job-ready as a junior DE in **6–12 months**.
- **Already a developer/analyst:** **3–6 months** to pivot.
- **Student alongside college:** treat it as a long game — **12–18 months** of consistency beats cramming.

## Portfolio > certificates
Employers care far more about **what you've built** than which course you bought. Aim for 2–3 solid projects on GitHub with a clear README. We suggest specific projects in each roadmap.

> **Key takeaway:** Build more than you watch, type everything, befriend error messages, and stay consistent through the week-6 wall. Now pick your roadmap below.

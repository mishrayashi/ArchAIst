If you want a tighter, high-intensity plan (≈20 hrs/week) to reach junior **Data Engineer** interview-readiness, here it is. Adjust dates to your pace — consistency matters more than speed.

## Month 1 — Foundations & SQL
- **Week 1:** Foundations section + Python setup. Daily: 10 small Python exercises.
- **Week 2:** Python deep — lists, dicts, functions, files, pandas intro. Build a CSV cleaner.
- **Week 3:** SQL fundamentals — SELECT/WHERE/JOIN/GROUP BY. Solve 50+ SQL problems.
- **Week 4:** Advanced SQL — windows, CTEs, subqueries. **Mini-project:** API → clean → load to DB.

## Month 2 — Engineering core
- **Week 5:** Data modelling — star schema, fact/dim, **SCD types**.
- **Week 6:** ETL/ELT concepts + build a pipeline with Python + a scheduler.
- **Week 7:** PySpark fundamentals — DataFrames, transformations, joins at scale.
- **Week 8:** One cloud + one warehouse (e.g. GCP + BigQuery, or AWS + Redshift). Load & query.

## Month 3 — Production, design & interviews
- **Week 9:** Airflow — build a real DAG with dependencies, retries, scheduling.
- **Week 10:** **The capstone project** — end-to-end pipeline (ingest→store→transform→warehouse→orchestrate). Write a great README.
- **Week 11:** System design (**HLD/LLD**) + data quality + Git/Docker basics.
- **Week 12:** Full interview drill — Interview Bank daily, company-specific sets, mock interviews, polish resume, start applying.

<div class="callout callout-tip"><span class="cfor">💡</span><div><strong>Daily rhythm that works:</strong> 30 min review (yesterday + a few interview questions) → 60–90 min new learning → 30–60 min building. End each day by committing code to GitHub. Small daily wins compound.</div></div>

<div class="callout callout-warn"><span class="cfor">⚠️</span><div>90 days is ambitious and assumes real focus. If life is busy, double the timeline — that's completely fine. The plan's <em>order</em> matters more than its speed.</div></div>

> **Key takeaway:** Month 1 = SQL + Python. Month 2 = engineering core. Month 3 = production + interviews. One capstone project, drilled daily, plus consistent interview practice = job-ready.

The **Data Engineer (DE)** builds and maintains the systems that collect, store, and transform data so that analysts, scientists, and AI models can use it. If data is water, the DE builds the plumbing.

## What you actually do day-to-day
- Write **pipelines** that move data from sources (apps, APIs, files) into storage.
- Clean, join, and reshape data with **SQL** and **Python/PySpark**.
- Design **data models** (how tables relate) and build **data warehouses**.
- Schedule and monitor jobs with **orchestration** tools (Airflow).
- Make pipelines **reliable, fast, and trustworthy** (data quality, testing, alerting).
- Manage cost and performance on the **cloud**.

## The skill stack
| Layer | Tools you'll learn here |
|-------|-------------------------|
| Language | **Python**, **SQL** (non-negotiable) |
| Big data | **Apache Spark / PySpark** |
| Storage | Data lakes (S3/ADLS/GCS), warehouses (**Snowflake, BigQuery, Redshift**) |
| Pipelines | **Airflow**, dbt, batch + **streaming (Kafka)** |
| Cloud | One of **AWS / Azure / GCP** |
| Modelling | Dimensional modelling, **SCD**, normalization |
| Foundations | Linux basics, Git, **HLD/LLD** (system design) |

## Rough salary signal
Among the highest-paid non-managerial tech roles. In India, mid-level DEs often out-earn equivalent web developers; in the US, senior DEs commonly reach the top tech pay bands. *(Numbers vary wildly by country, company, and year — treat as direction, not promise.)*

1. Master **SQL** + **Python**.
2. Learn **one cloud** + a **warehouse** + **Spark** + **Airflow**.
3. Build **2–3 portfolio projects** (an end-to-end pipeline is gold).
4. Learn **data modelling** and **system design** for interviews.
5. Drill the **Interview Bank** here, especially SQL and pipeline design.

> **Key takeaway:** The DE builds reliable data pipelines and warehouses. It's the most beginner-accessible, in-demand role and the launchpad for everything AI.

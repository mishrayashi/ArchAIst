========================================================
  ArchAIst — from zero to AI architect
========================================================

TO OPEN:  double-click  "index.html"

It opens in your web browser. The lessons work fully
offline; the built-in Code Runner (Python + SQL) needs
internet the first time (or host on GitHub Pages).
No installation or account needed.

Start with the "Foundations (Level 0)" section if you
are a complete beginner. Your progress saves automatically
in this browser.

(If the copy-code buttons don't work when opened directly,
 open a terminal here and run:  python -m http.server 8000
 then visit  http://localhost:8000  in your browser.)

See README.md for the full guide and how to add your own
lessons and interview questions.
